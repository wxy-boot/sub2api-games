## 坑

- `src/http.js` 启动时把 `public/` 读进内存，改前端文件必须重启服务才能看到效果（预览时踩过）。
- 结算浮层若用 setTimeout 延迟 `data-state`，会打破 `tests/game.test.js` 的同步断言；正确做法是立刻设 state、只延迟视觉可见性（class）。

## 二轮改版（对齐 sub2api 浅色工作台）

用户反馈：嵌入方 sub2api 是浅色工作台（灰底白卡 + 绿色点缀），之前的深色青绿背景割裂；首页太空；游戏页按钮散在画布外。

- 设计系统改为 **浅色优先**：`--bg #f4f6f9`、白卡片、`--line #e6eaf0`、品牌绿 `#0f9e91` 只做点缀；深色改为中性 slate（不再青绿），`theme` 默认 `light`，`dark/auto` 仍可选。
- 首页：`ready` 只有 1 个游戏时改用 spotlight（左插画 + 右信息 + 指标 + CTA），多游戏时回落网格；重复的“已上线”徽章与提示去掉。
- 游戏页：删掉画布下方的 stage-bar，把 暂停/重开/音效/全屏 收进画布卡片顶栏（`stage-head` + `tool-icon`），加状态点与状态文案（准备开始/进行中/已暂停/已结束）；方向键也搬进卡片；键盘提示只在 fine pointer 显示，触屏显示滑动提示。
- 操作方式面板改成键帽（`kbd`），`controls` 结构变为 `{keys,label,touch?}`；`?` 触屏行在桌面隐藏。
- 结算浮层改为轻遮罩 + 重模糊（`--scrim` .08 + blur 9px），白卡片靠阴影浮起；死亡动画延后 420ms 仍保留。
- 画布：浅色棋盘（`--snake-board-*`），网格 alpha 0.055；画布内 HUD 改白色胶囊并读 `--snake-hud-*`；桌面棋盘比例 0.76。

### 坑

- **SVG 里 `var()` 不可靠**：`stop-color="var(--x)"` 乃至 `style="stop-color: var(...)"` 在 Chrome 首次绘制时取不到变量（回落到 fallback），只有 JS 后置修改才生效。正确做法是让插画背景透明，由外层 CSS 渐变提供底色；需要主题化的 SVG 属性一律改用 CSS 类或运行时 setAttribute。
- 画布卡片用 `width: fit-content` 会和外层测宽形成回环：加了 `.stage-column` 包裹层，外壳只测列宽。
